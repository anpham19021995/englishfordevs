# MVP Scope

## Goal

Build an AI-powered English learning platform for software engineers.

## Target Users

- Backend developers
- Frontend developers
- QA engineers
- DevOps engineers

## Core Features

### 1. AI Chat Practice

- Chat with AI in IT scenarios
- Grammar correction
- Vocabulary suggestions

### 2. Interview Practice

- Mock interview mode
- AI feedback
- Technical English improvement

### 3. VN -> English Converter

- Convert Vietnamese IT explanations into natural English

## NOT included in MVP

- Mobile app
- Multiplayer
- Video call
- Complex gamification
- AI avatar
